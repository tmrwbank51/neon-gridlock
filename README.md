Neon Gridlock — a rush-hour traffic-light controller game. You run the signals of a tiny neon city: switch the lights, keep the traffic flowing through six waves from morning calm to the midnight surge, clear the way for ambulances and fire trucks, mind the pedestrians, and pick upgrades between waves. Conflicting greens crash. Jams cost lives. Smooth flow builds your combo.

Pure Canvas 2D and vanilla JavaScript, no libraries, no assets — every pixel and sound is generated by the code. Seeded and replayable: open `game/index.html?seed=123` to replay a run.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. Or simply open `game/index.html` directly.
